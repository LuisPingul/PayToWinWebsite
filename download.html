03 // TROUBLESHOOTING & SECURITY

Windows SmartScreen & Release FAQ

Common questions when installing an indie Unity Windows build, verifying file integrity, or launching on Windows 10/11.

Windows shows "Windows protected your PC" (SmartScreen warning) when opening the installer or .exe

Student and indie Unity builds compiled without a paid commercial Authenticode code-signing certificate trigger Microsoft Defender SmartScreen on first launch.

  1. First verify the downloaded file's SHA-256 hash matches the checksum shown in the File Verification & Integrity panel above.
  2. In the SmartScreen prompt, click More info, confirm the filename matches, and select Run anyway.
Why do I get an error about missing UnityPlayer.dll or PayToWin_Data when running a portable .zip build?

Unity Standalone Windows builds are not single self-contained binaries unless wrapped in an installer. If you downloaded a .zip archive, you must extract the entire archive to a folder (for example C:\Games\PayToWin\) before double-clicking PayToWin.exe.

Keep PayToWin.exe, UnityPlayer.dll, PayToWin_Data/, and MonoBleedingEdge/ (or GameAssembly.dll) together in the same directory—do not drag only the .exe onto your Desktop.

How do I verify the SHA-256 checksum on Windows before running the build?

Open Windows Terminal or PowerShell in your Downloads folder and run the verification command copied from the Verification panel above: 

Get-FileHash ".\PayToWin_Setup_v2.0.60.exe" -Algorithm SHA256

Compare the printed 64-character hex string (case-insensitive) with the official SHA-256 hash listed on this page and on GitHub Releases. If they do not match, re-download the package before executing it.

Is Pay to Win available for macOS, Linux, or mobile devices?

No. Pay to Win is currently built and tested exclusively for Windows 10 / Windows 11 (64-bit x86_64) using Keyboard & Mouse controls. macOS, Linux, and mobile builds are not supported in Milestone v2.0.60.
